# 🌾 Smart Crop Irrigation Prediction System

An end-to-end Machine Learning pipeline designed to optimize agricultural water usage by predicting crop irrigation requirements based on crop_related environmental, soil, and atmospheric conditions.

---

## 📌 Project Overview
Precision agriculture leverages data-driven insights to make resource management efficient. This project implements and evaluates **6 Machine Learning Classifiers** to determine whether a crop requires irrigation (`1`) or not (`0`). 

By prioritizing **Recall (1.0000)** and minimizing **False Negatives**, the system ensures 100% crop moisture safety while drastically reducing unnecessary water consumption.
